# Согласованные решения — «Справочник мест»

Дата фиксации: **15.11.2026**. При расхождении с устными предположениями применять пункты этого документа; новые решения дописывать с датой.

## 1. Навигация и главная страница

Сейчас две кнопки: «ИССЛЕДОВАТЬ КАРТУ» и «КАТЕГОРИИ». После разработки справочника сделать три кнопки на одной горизонтальной линии, **весь ряд центрировать как единое целое**:

| Слева | По центру | Справа |
|---|---|---|
| **ИССЛЕДОВАТЬ КАРТУ** | **КАТЕГОРИИ** | **СПРАВОЧНИК** |
| Золотая (primary) | Тёмная (secondary) | **Золотая (primary)** |

- Кнопка «СПРАВОЧНИК» должна быть **точно того же размера и цвета**, что и «ИССЛЕДОВАТЬ КАРТУ»: использовать общую `.hero__button` + `.hero__button--primary`, не копировать отдельные цвета.
- В исходном `src/pages/HomePage.css` `.hero__button` имеет `min-height: 66px; min-width: 230px`; золотая кнопка использует `linear-gradient(135deg, #f4d58d, #c99645)`. Сохранять единый стиль и по возможности вынести общие токены в централизованный файл.
- На узком экране кнопки аккуратно складываются в колонку; текст не обрезается и не выходит за экран.
- Кнопка должна вести в **рабочий** публичный раздел `/directory` (предлагаемый URL; перед реализацией сверить конфликты маршрутов и SEO).

## 2. Не седьмая категория

- Шесть исходных категорий объявлений остаются без изменений.
- «Справочник» — отдельная главная секция сайта, доступна без покупки тарифа.
- В админке добавить самостоятельный раздел **«Справочник мест»** с внутренними вкладками. В существующей админке уже есть «Справочники» (`/dictionaries`) для наборов значений. **Не смешивать** их с новым каталогом географических объектов.

Предлагаемые вкладки в новом разделе:
- Реки и водоёмы
- Леса и природные территории
- Охотничьи угодья
- Достопримечательности и интересные места
- Виды рыб и животных (переиспользовать существующие справочники значений, если это возможно после проверки контрактов)
- Регионы и населённые пункты (переиспользовать действующие данные, не плодить дубли)

## 3. Два типа содержания

| Сущность | Справочный объект | Объявление |
|---|---|---|
| Задача | Достоверные сведения о месте | Коммерческое или частное предложение |
| Для читателя | Бесплатно | Просмотр по действующим правилам сайта |
| Публикация | Без тарифа, после модерации | По тарифным правилам объявлений |
| Собственная карточка | Да | Да, существующая |
| Отображение на карте | Линия / область / точка | Отдельный маркер |
| Жизненный цикл | Черновик → проверка → публикация → архив | Существующий жизненный цикл объявлений |
| Связь | Может иметь связанные объявления | Может ссылаться на справочный объект |

Первоначальное наполнение справочника — через администратора. Будущая бесплатная подача сведений пользователями возможна только после добавления очереди модерации и защиты от спама. **Не трактовать бесплатность информации как право автоматически публиковать любой пользовательский текст.**

## 4. Пример реки Дон

- Геометрия длинной реки — **линия**, для больших объектов возможно несколько именованных участков. Подсветка по нажатию, переход в карточку реки/участка.
- В карточке: название, регион, описание, фотографии с правами использования, виды рыб с проверенными источниками, особенности доступа, связанные места и объявления.
- Рыбу не приписывать водоёму без подтверждения. Указывать источник данных и дату их проверки; при необходимости — сезонные/региональные ограничения.
- На карте пользователь включает/выключает **два независимых слоя**: «Справочник» и «Объявления».
- Озёра и угодья — полигоны; небольшие интересные места — маркеры.

## 5. Что сохраняем

Не переделывать с нуля существующие React, PHP API, БД, Leaflet, админку, учётные записи, шесть категорий, объявления, оплаты и SEO-патч. Расширение модульное, без жёсткого зашивания списков рек и рыб в JSX/PHP.
