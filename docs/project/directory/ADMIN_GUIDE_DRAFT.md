# Справочник мест — будущая инструкция для администратора

**Статус:** предварительная пользовательская документация. Экран, кнопки и API ещё не реализованы. Обновлять одновременно с каждым патчем; не выдавать описание ниже за готовую функцию.

## Кто сможет пользоваться

- Администратор — создавать, редактировать, публиковать, архивировать, назначать геометрию, проверять источники.
- Модератор — проверять/одобрять согласно утверждённым правам (матрица разрешений будет уточнена при реализации).
- Посетитель — читать опубликованные записи бесплатно без регистрации.

## Планируемый путь по интерфейсу

`/admin/` → **Справочник мест** → вкладка типа объекта → **Добавить**.

Новый пункт не подменяет уже существующий `/admin/dictionaries` («Справочники»: группы и значения — в том числе рыба/дичь).

## Планируемое заполнение реки

1. Выбрать **Реки и водоёмы** → тип «Река».
2. Ввести название, регион, краткое описание, основную информацию.
3. Задать подтверждённый GeoJSON участка реки: загрузка готовой геометрии либо редактор после его реализации. В админке нужен предварительный просмотр контура.
4. Прикрепить источники геоданных, сведения о рыбе, фотографии и их авторство/лицензию.
5. Сохранить **черновик**; проверить, что он не виден публично и отсутствует в sitemap.
6. Отправить на модерацию, затем опубликовать.
7. Проверить ссылку на публичную карточку, линию на карте и независимость от объявлений.

## Как будут выглядеть записи

- Река — подсвеченная синяя линия (или отдельные участки) и информационная карточка.
- Озеро — область на карте и информационная карточка.
- Угодья — область по проверенным границам, без утверждения о свободном праве охоты.
- Достопримечательность — маркер и карточка.

## Ограничения первой версии

- Не все названия рыб из старого demo-списка являются подтверждёнными данными о водоёмах.
- Нельзя массово импортировать геометрию из растровых карт.
- Пользовательское добавление справочных записей запланировано позднее, только через модерацию.
- Правила тарифов для объявлений отдельно; справочник не создаёт платеж.

## Реализовано в v0.1 (после установки SQL и PHP)

1. Войти в `/admin/` под **администратором**.
2. Открыть меню **«Справочник мест»** (`/admin/directory`).
3. Выбрать вкладку, нажать **«Добавить черновик»**.
4. Ввести тип, название, латинский `slug`, регион, описания; источник и GeoJSON можно добавить позже.
5. Нажать **«Сохранить черновик»**. Запись попадает в таблицу этой вкладки.
6. Нажать **«Редактировать»** — изменить черновик.

В v0.1 запись **не видна посетителям, не входит в sitemap и не отображается на карте**. Роль модератора не имеет доступа к этому экрану. При неустановленном API увидите сообщение о недоступности серверного модуля; это не признак потери данных.

## Устранение 404 при обновлении `/admin/directory` (v0.1.1)

Админка — React SPA c `BrowserRouter basename="/admin"`. Если открыть меню «Справочник мест», а затем нажать F5, веб-сервер обязан отдать `admin/index.html` для маршрута `/admin/directory`. Без этого возможна публичная страница 404.

Корректировка находится в корневом `.htaccess` (НЕ `api/.htaccess` и НЕ PHP-модуль): после резервной копии сравните действующий `.htaccess` с патчем, затем добавьте правило для admin SPA выше общего `RewriteRule ^ seo-router.php [L,QSA]`. Нельзя удалять действующие SEO-перенаправления, генерацию sitemap и обработку публичных адресов.

## v0.2 — импорт GeoJSON и предварительный просмотр (код подготовлен)

**Роль:** администратор. **Страница:** `/admin/directory`. **Публичного отображения ещё нет.**

1. Выберите вкладку «Реки и водоёмы» и нажмите «Редактировать» напротив уже сохранённого черновика «Дон».
2. Получите **проверенный** файл `.geojson` небольшого участка. См. `geodata/README.md` в документации.
3. В форме рядом с «Геометрия GeoJSON» нажмите **«Выбрать файл .geojson / .json»**. Можно также вставить валидный GeoJSON в текстовое поле.
4. Дождитесь проверки: откроется карта с линией реки/контуром водоёма. Контролы `+`, `−` и `⌖` изменяют только просмотр.
5. Заполните поле «Источник сведений (ссылка)», проверьте лицензию и нажмите «Сохранить черновик».
6. Обновите админку F5 и повторно откройте объект: контур должен сохраниться и снова показываться.
7. При ошибке файла («превышает 250 КБ», «неверные координаты», «несовместимая геометрия») используйте меньший или исправленный файл. Нельзя рисовать вымышленные координаты.

В админке не устанавливаются новые npm-пакеты. Исходные файлы PHP, база MySQL и платная модель объявлений патчем v0.2 не меняются. Фактическая проверка загрузки на рабочем хостинге остаётся задачей после выкладки.

## v0.3 — публикация

После загрузки v0.3 в таблице справочника для черновиков появится кнопка «Опубликовать». Перед действием админ подтверждает публикацию. PHP API проверяет длину и различие текстов и наличие источника; черновик «Дон» с повторяющимся кратким и подробным текстом **не пройдёт проверку, пока описание не будет дополнено**. При успехе появится кнопка «Открыть» и «Снять с публикации». Изменить опубликованную запись непосредственно нельзя — сначала вернуть в черновик.

Ссылки: `/directory`, `/directory/river/don`, общая `/map` с двумя переключателями. Виды рыб и дополнительные сведения пока отсутствуют. Участок Дона можно просматривать без новых координат из админки v0.2.
