# Native Places — v0.4b: справочник видов и фотографии (пакет для установки)

**Дата подготовки:** 16.11.2026. **Статус:** КОД ПОДГОТОВЛЕН, на хостинге **НЕ УСТАНОВЛЕН**. Последняя реально проверенная версия: публичная v0.3, админская v0.4a.

## Что реализовано в коде

- Вкладка **«Виды рыб»** внутри `Справочник мест → Реки и водоёмы`; единая база видов (`directory_species`). Данные: русское и научное названия, slug, описания, статус черновика. База подготовлена и для птиц/млекопитающих/растений; UI этой итерации показывает только рыб.
- Связи **вид → река или водоём → (необязательный) конкретный участок**. У каждой связи обязательны источник из `directory_sources`, тип доказательства и дата проверки; привязка к чужому участку запрещена. Из одного факта присутствия в реке нельзя автоматически делать вывод о каждом участке. Запрещено выбирать источник типа `osm`/`licensed_media` для подтверждения рыбы.
- Медиатека видов: до 8 изображений на вид, JPEG/PNG/WebP, до 3 МБ исходник, после обработки ≤2 МБ и ≤1600 пикселей по большей стороне. Запрашиваются автор, лицензия/основание, URL оригинала, attribution, подтверждение прав. Сервер декодирует и пересохраняет фото через **PHP GD**, убирая EXIF/геометки. Фото можно удалить, неверную связь — удалить.
- **Решение о приватности:** байты изображений сохраняются в `directory_media.image_data` (MySQL `MEDIUMBLOB`). Они **не** лежат в общедоступной `uploads/`; `/api/admin/directory/media/image.php` требует сессию администратора. Поле `storage_path='db:private'` — маркер типа хранилища, НЕ путь к веб-файлу. Это осознанное начальное отклонение от первоначального проекта файлового хранилища; перед масштабным наполнением стоит вынести медиа в закрытое хранилище вне docroot. Считайте стоимость резервного копирования БД.
- **Только черновики:** в этой версии НЕТ публикации видов, фотографий, occurrences, публичных страниц видов, API для посетителей, Sitemap-записей видов. Опубликованный Дон и текущая карта неизменны. SQL затрагивает только четыре новые таблицы.

## Состав патчей

**SOURCE ZIP:** `admin/src/pages/Directory/DirectoryPage.jsx`, `admin/src/shared/api/directoryApi.js`, новые `admin/src/pages/Directory/species/`, тесты, текстовые копии серверных файлов в `docs/backend/`, проектная документация. Никакие исполняемые PHP не кладём в локальный проект.

**HOST ZIP:** `api/admin/directory/species/{_bootstrap,index,save}.php`, `api/admin/directory/occurrences/{_bootstrap,index,save,delete}.php`, `api/admin/directory/media/{_bootstrap,index,upload,delete,image}.php`, `db/migrations/20261116_directory_species_media_v04b.sql`. Старые файлы API не заменяются. В `/www/native-places.ru/admin/directory/` файлы НЕ класть — физический каталог уже вызывал 301/403!

## Проверки и ограничения

- Локальная статическая валидация, PHP lint, тесты — результаты записать при упаковке.
- **Не проверено без установленного окружения:** работа MySQL/MariaDB с миграцией, наличие расширения PHP GD на хостинге, фактическая загрузка фото, сборка Vite на Windows, работа CSRF и авторизации в production.
- Связь occurrence можно создать только с указанным источником. Выбор источника — ручная ответственная проверка: код не способен подтвердить фактическую ихтиофауну.
- Фотографии из интернета нельзя копировать без разрешения или подходящей лицензии. Отсутствие фото лучше нарушения прав.
- Нет массового импорта рыбы или автоматического заполнения фактов. Все сведения — из проверяемых источников.

## Следующая фаза после установки

1. Проверить API без сессии (401 JSON); в админке создать **тестовый черновик** вида без утверждений о распространении.
2. Зарегистрировать научный/официальный источник, создать корректную связь с Доном (только если есть доказательства).
3. Проверить PHP GD и добавить собственное/лицензионное фото, повторно открыть после F5 и проверить приватный просмотр.
4. Позднее разработать модерацию, публикацию видов/фото, публичные блоки на страницах Дона, отдельные SEO-страницы, при сохранении защиты черновиков.
