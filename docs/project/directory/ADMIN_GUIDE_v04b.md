# Native Places — инструкция администратору v0.4b

**Статус:** v0.4b и v0.4b.1 установлены и проверены по черновикам и привязке окуня; пункт про тип ИИ-изображения относится к подготовленной v0.4b.2. Требуется сессия администратора.

## Навигация

`Админка → Справочник мест → Реки и водоёмы → Виды рыб`.

**«Добавить вид рыбы»**: название, латинский slug (например, `okun`), необязательное научное название, краткий и подробный тексты. Нажать «Сохранить черновик вида». Вид хранится один раз, а не создаётся заново для каждого участка реки. Не утверждать присутствие в Дону автоматически.

**«Открыть» вид → «Привязать к реке или участку»**: выбрать реку/водоём из уже существующих объектов. По желанию выбрать дочерний участок; поле «участок» оставлять пустым, если достоверна только информация о реке в целом. Выбрать уровень подтверждения, дату и **источник именно этого утверждения**. Если источника нет — сперва создать его в форме «Добавить источник»: тип `official`, `scientific` или `observation`, название, дату проверки и доступные реквизиты. **URL необязателен для всех типов источников.** Если это бумажная книга или справочник, внесите автора/издателя, издание, год и страницы в поле комментария. Для личного наблюдения укажите автора/наблюдателя, место, примерный период и что именно наблюдалось. Если ссылка существует, укажите реальную HTTP(S)-ссылку; фиктивные адреса запрещены. Источник OSM подтверждает географию, **не** наличие вида рыбы. Нажать «Сохранить черновик связи». Неверную связь можно удалить.

**«Открыть» вид → «Изображения вида»**: `Загрузить изображение`. JPG/PNG/WebP до 3 МБ. Сначала выбрать тип: **«Фотография»** (автор и лицензия/основание обязательны) или **«Иллюстрация, созданная ИИ»** (ввести инструмент генерации, например ChatGPT; отдельная лицензия на стороннее фото не нужна). Для чужих фото фиксировать права и, если доступны, URL оригинала/лицензии. В обоих случаях требуется подтверждение права использования. ИИ-изображение не выдавать за реальную фотографию рыбы. Для очистки EXIF/GPS сервер обязан иметь GD. После загрузки фото видно только администратору. Если GD не установлен — не пытайтесь обойти проверку загрузкой картинки на публичный хост; остановиться и сообщить текст ошибки.

**Редактирование:** выберите вид → `Редактировать описание`; фотографии при необходимости удалять и загружать заново; связи можно редактировать и удалять пока это черновики. Удаление фото необратимо.

## Что пока НЕ работает

- Нет кнопки публикации вида и его фотографий; никаких фото/перечней видов на публичной странице Дона, не появляются в Sitemap.
- Нет проверки научных фактов автоматически, поиска лицензий или юридического аудита фото.
- Нет публикуемых страниц отдельных участков (v0.4a черновики).

## Предварительные данные о виде для теста

Можно проверить CRUD только по нейтральной записи без утверждения о распространении, например название «Окунь» и slug `okun`; *не создавать* связь с Доном до проверки наличия по источнику. Не загружать изображения из результатов поиска без прав.
