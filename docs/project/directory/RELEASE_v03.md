# Native Places — v0.3: публикация и публичный справочник

Дата подготовки: **15.11.2026**. Версия — **код подготовлен, production не развёрнут**. Предыдущие версии v0.1–v0.2 установлены и проверены пользователем на хостинге.

## Подготовлено в v0.3

1. **Публикация администратором**: `POST /api/admin/directory/publication.php` с `id`, `action=publish|unpublish`, CSRF-токеном, правами admin и аудитом `directory_entry_events`. Опубликованные записи нельзя редактировать: сначала снять с публикации.
2. **Публичные API (только published)**: `GET /api/directory/index.php` (24 объекта/страница), `show.php?type=river&slug=don`, `map.php` (пилотный предел 60 объектов с геометрией). При снятии с публикации публичные API перестают выдавать объект.
3. **Публичные страницы**: `/directory` и `/directory/:type/:slug`, карточка с описанием, источником и картой GeoJSON. Посещение бесплатно, платёжный код не вызывается.
4. **Главная**: три центрированные кнопки; «Исследовать карту» и «Справочник» одинакового золотого цвета и размера, «Категории» остаётся тёмной. Не добавлена седьмая категория.
5. **Карта**: два независимых переключаемых слоя (маркеры объявлений / геометрии справочника), реки линиями, территории полигонами, точки окружностями с popup-ссылкой.
6. **SEO**: серверные HTML-снимки для списка/деталей, 404 для черновиков, 503 при ошибке БД, canonical, breadcrumbs, Place JSON-LD, новый раздел в динамическом sitemap только при наличии опубликованных объектов. На пустом `/directory` — noindex. Новые карточки индексируются только после публикации.
7. **Документация и тесты**: PHP текстовыми копиями под `docs/backend`, SEO PHP под `docs/seo`, планы и инструкции — здесь.

## Не входит в v0.3

- Справочник видов рыб, животных, историй, фотографий, привязка объявлений к водоёмам.
- Добавление справочных объектов обычными посетителями и полноценный поток модерации.
- Редактирование опубликованного объекта напрямую (пока: снять с публикации → изменить → повторно опубликовать).
- Пространственный индекс, обрезка геометрии на сервере по bbox/zoom. `map.php` отдаёт максимум 60 опубликованных объектов с геометрией и возвращает `truncated`. Перед массовым наполнением этот endpoint необходимо расширить.
- Исполнение этих изменений на хосте: нужна установка и проверка.

## Безопасность

- Справочные данные отделены от `places` и платёжных таблиц; никаких новых тарифов.
- Все публичные SELECT содержат `status='published'` и не возвращают admin ID, аудит, черновики.
- Публикация требует роль `admin`, PHP-сессию, CSRF, транзакцию и подтверждение в UI.
- Перед публикацией: краткое описание ≥40 символов, отдельный текст ≥120 символов, тексты не одинаковы, указан URL источника. Это минимальный барьер, а не экспертная проверка качества.
- Границы охотугодий нельзя трактовать как подтверждение разрешённой охоты. Карточки должны содержать проверяемые сведения.
- Серверный HTML кешируется штатными правилами SEO-хелпера до 300 секунд: после снятия с публикации API закрывает запись немедленно, но ранее сохранённые HTML-копии/поисковые кеши могут обновиться не сразу. Динамические JSON API — `no-store`.

## Проверки при подготовке

- `php -l` для 5 новых PHP эндпоинтов, SEO PHP, `seo-router.php`, `sitemap.php` — без синтаксических ошибок.
- 18 локальных Node-тестов (API/SEO-контракты, SEO-база, URL, кнопки) — PASS.
- Проверки PHP против живой MySQL, полный Vite build, React в браузере и хостинг — **ещё не выполнялись**, не считать развернутым.

## Документация по раскладке

- **SOURCE ZIP** — изменения локального React/Vite проекта, копии серверных файлов в `docs/backend`, PHP SEO-источники для синхронизации, инструкции. Не содержит рабочую папку `api/`.
- **HOST ZIP** — реальные PHP файлы `api/directory/*`, `api/admin/directory/publication.php`, `seo/directory.php`, обновлённые `seo-router.php`, `sitemap.php`, `seo/config.php`, `seo/snapshots.php` и инструкция. Не содержит изменённых платёжных API или миграций.
- На сервер отдельно загружаются **результаты сборки** локальных `dist` (корень сайта) и `admin/dist` (папка админки). Не загружать туда JSX-файлы вместо сборки.
