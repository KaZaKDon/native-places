# Native Places — v0.4: модульная структура, маршруты и карты

**Статус:** карта будущих компонентов и взаимодействий, не перечень уже написанного кода.

## Текущая работающая v0.3

```text
https://native-places.ru/
  ├── /categories — шесть существующих платных категорий
  ├── /map — объявления + справочник, независимые галочки
  └── /directory — бесплатный каталог
       └── /directory/river/don — карточка Дона

admin/src/pages/Directory/DirectoryPage.jsx — базовые объекты и публикация
api/admin/directory/{index,save,publication}.php — административный API
api/directory/{index,show,map}.php — публичный API (только опубликованные)
seo-router.php, seo/directory.php, sitemap.php — серверный SEO
```

## Будущие маршруты и условия индексирования

| Маршрут | Назначение | Условия |
|---|---|---|
| `/directory` | Бесплатный каталог | Уже есть |
| `/directory/river/don` | Общая река | Уже есть |
| `/directory/river/don/segments/{slug}` | Конкретный участок | Предложение v0.4a; добавлять в Sitemap **только при уникальном полезном тексте и публикации** |
| `/directory/species/{slug}` | Вид рыбы или растения | Предложение v0.4b; только опубликованные содержательные записи |
| `/directory/protected_area/{slug}` | ООПТ | Предложение v0.4c, согласуется с новым `type`; публичный slug формат можно до начала кода выбрать отдельно |
| `/map?directory=...` | Фильтр/фокус карты | Параметры не должны порождать индексируемые дубли; canonical на стабильный URL |

**Черновик** и неполный объект: публичный API не возвращает его, прямой URL выдаёт 404 без индексирования, в Sitemap его нет. В родительской карточке при отсутствии сведений не показываем пустую вкладку. Не генерировать десятки низкокачественных SEO-страниц из одной строки в БД.

Пути — проектные, **не** готовые адреса API. Сохранить разделение: API реально на хостинге, `docs/backend` — текстовая документация. ZIP с React/документами и ZIP с PHP/SQL — отдельно.

## Карта: приоритет слоёв

1. Подложка OpenStreetMap.
2. Полигоны природы (зелёный), угодий (охра), ООПТ (фиолетовый) — прозрачные; границы видны.
3. Синие реки; выбранный участок выделяется дополнительной подложкой.
4. Маркеры интересных мест.
5. Маркеры платных объявлений — независимый слой.

Клик по Дону открывает текущий popup реки. Внутри карточки Дона выбирают отдельный участок; карта подводит к **проверенной** геометрии участка. На общей карте по умолчанию **не** рисовать каждый сегмент повторно поверх линии Дона. При пересечении ООПТ и реки обе сущности доступны отдельно.

## Платная и бесплатная части

- `directory_*` — справочные сведения, **без оплаты и цен**.
- `places`, `payments` и действующие правила объявлений — не меняем.
- `directory_related_places` — только ссылки на действующие оплаченные/опубликованные предложения, после проверки реальной схемы и API.
- «Справочник» — самостоятельная кнопка на главной, не седьмая категория объявлений.
