# Два черновика ООПТ для редакторского ввода

**19.11.2026.** Тексты основаны на сведениях учреждения/госорганов. Не являются заключением о текущем режиме доступа или о точном положении границ. Для начала создать **черновики** в «Админка → Справочник мест → Природные территории». Контуры не загружать до получения официального GeoJSON/координат с проверяемой датой. Не заменять границы прямоугольником по району. Перед публикацией сверить актуальность ссылок и статус в официальном реестре.
