**Актуально на 17.11.2026, после развёртывания и проверки v0.4b.2.**

## Что читать первым

1. **`MASTER_PLAN_AND_STATUS.md`** — единый полный реестр концепции, уже выполненного, незавершённых проверок, всей очереди функциональности, SEO/карты/объектов и регламента обновления документации.
2. **`HANDOFF.md`** — короткая точка продолжения работы в новом чате.
3. **`CURRENT_DECISIONS.md`** — живой журнал утверждённых решений и открытых вопросов.
4. **`VERIFICATION_v0.4b2_2026-11-17.md`** — реально подтверждённые тесты последнего этапа; без смешения с планом.

- `DECISIONS_2026-11-15.md`, `DECISIONS_2026-11-16.md` — исходные договорённости, не переписываются задним числом.
- `DIRECTORY_SCOPE_v04.md`, `MAP_COLORS_v04.md`, `DATA_MODEL_v04.md`, `ADMIN_STRUCTURE_v04.md` — полный состав и первоначальная архитектура.

### Основные требования

Справочник — **бесплатный**, не седьмая категория объявлений. API и MySQL находятся на **хостинге**, локально — React и текстовые зеркала PHP. Черновики скрыты. ZIP-патчи только изменённых файлов, по одному шагу, каждый этап — со свежей документацией, описанием установки и отката.
