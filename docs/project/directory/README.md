# Native Places — отдельный бесплатный «Справочник мест»

**Версия документации:** v0.3, 15.11.2026. **v0.3 не установлен на хост:** файлы подготовлены. Начальная точка для нового чата — `HANDOFF.md`.

- `DECISIONS_2026-11-15.md` — утверждённая модель продукта и внешний вид.
- `ARCHITECTURE.md` — модульное устройство БД, API, геометрии, карты и SEO.
- `DELIVERY_PLAN.md` — история версий и дальнейшие этапы.
- `RELEASE_v03.md` — фактический состав v0.3, проверки и ограничения.
- `PUBLISHING_GUIDE.md` — пошаговая инструкция администратора.
- `ADMIN_GUIDE_DRAFT.md` — геометрия, черновики, публикация.
- `HANDOFF.md` — текущее состояние и порядок продолжения.
- `geodata/` — инструкции извлечения подтверждённых OSM-геоданных.

**Принцип:** объявления платные и остаются в шести категориях; информационные объекты бесплатны и живут в отдельных таблицах. Только опубликованные объекты попадают в публичный API, карту и SEO.
