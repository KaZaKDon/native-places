# Native Places v0.4a — инструкция развёртывания и откат

## Где что находится

- **Локально:** `E:\Project\native-places` — React и документация, API только в виде текстовых копий `docs/backend/`.
- **Хостинг:** `/www/native-places.ru/` — рабочая админка, PHP API и база MySQL/MariaDB (имя базы проверять в phpMyAdmin).
- **Source ZIP:** новые/изменённые файлы админки + docs + тесты. Нет выполняемого серверного PHP.
- **HOST ZIP:** 6 новых PHP и один `.sql` с сохранением относительных путей. Нет замены существующего API.

## Порядок установки (только после подготовки и проверок)

1. Создать резервные копии БД и действующих файлов API/админки; записать количество строк `directory_entries` и `directory_entry_events`.
2. **Проверить фактические схемы**: `SHOW CREATE TABLE directory_entries;` и `SHOW CREATE TABLE directory_entry_events;` — `id` первой должен быть `BIGINT UNSIGNED`, InnoDB, совместимая кодировка. Проверить существование `directory_sources`/`directory_segments`; при наличии сравнить схему, НЕ полагаться на `IF NOT EXISTS` как на миграцию столбцов.
3. В phpMyAdmin запустить только файл `db/migrations/20261116_directory_segments_v04a.sql` из HOST ZIP. Ожидаются 2 новые таблицы. Без проверки предварительного пункта **не запускать**.
4. На хостинг загрузить, сохраняя каталог, только новые файлы:
   - `api/admin/directory/sources/{_bootstrap,index,save}.php`
   - `api/admin/directory/segments/{_bootstrap,index,save}.php`
   Не заменять существующие `api/admin/directory/_bootstrap.php`, `index.php`, `save.php` и `publication.php`.
5. **Без входа** проверить GET `https://native-places.ru/api/admin/directory/sources/index.php` — ожидается JSON `401`. Проверить второй `segments/index.php?river_entry_id=1` аналогично. `404` HTML означает ошибку пути; `500` требует расследования логов и схемы.
6. Применить SOURCE ZIP в локальном репозитории. Собрать `npm --prefix admin run build`; после успешной сборки загрузить содержимое `admin/dist` в действующую корневую папку админки.
7. Открыть `/admin/directory` → «Реки и водоёмы» → «Участки рек». Создать тестовый черновик, F5, редактировать. **В публичный сайт новую сборку загружать не нужно.**

## Откат

- При ошибке UI: вернуть предыдущую сборку админки (резервная копия), браузер Ctrl+F5.
- При ошибке API: удалить/переименовать **только новые** PHP-папки `sources` и `segments`; вернуть версию админки.
- Новые таблицы могут оставаться — старое приложение их игнорирует. **Не удалять таблицы автоматически:** сначала экспортировать их данные, проверить внешние ключи и наличие черновиков, согласовать удаление. SQL DROP не поставляется намеренно.
- Не менять `places`, `payments`, Дона, `sitemap.php`, SEO router или `.htaccess`.

### Контроль безопасности

Публичных endpoint участков **нет**. Данные `directory_segments` не попадают в пользовательский справочник; не публиковать секретные координаты редких/охраняемых объектов.
