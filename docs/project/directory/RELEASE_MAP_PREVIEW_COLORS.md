# Цвет геометрии в предпросмотре админки

Патч после Native Places v0.4e. Данные и PHP не изменяются.

- `GeoJsonEditor` передаёт тип справочного объекта в `GeoPreviewMap`.
- Предпросмотр: реки/озёра синие `#258AD0`, леса/природные территории и точки зелёные `#619C70`, угодья охристые `#B68E4E`, ООПТ фиолетовые `#8B5CF6`. Прозрачность заливки соответствует публичному слою.
- Токены цветов админки сосредоточены в `admin/src/styles/variables.css`; код публичной карты остаётся прежним.
- В `MASTER_PLAN_AND_STATUS.md` обновлён статус фиолетового слоя.

Установка: скопировать содержимое `SOURCE/` в корень локального проекта с сохранением путей. Выполнить `npm run build` в `admin/` и заменить на хосте собранные файлы админки. Никаких миграций БД или PHP файлов для этого патча нет.

Проверка: откройте редактирование ООПТ с GeoJSON; четыре области в предпросмотре должны стать фиолетовыми, публичная карта остаётся фиолетовой. Для охотугодья предпросмотр должен стать охристым.

Локально на реконструированных исходниках `node --test` — 97/97. Сборка админки здесь не запускалась: `npm ci --offline` остановилась на отсутствующем в кэше пакете zwitch; в вашей установленной среде выполнить `npm ci` при необходимости и `npm run build`.
