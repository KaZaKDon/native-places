# Native Places v0.4b.1 — необязательная ссылка на источник

**Статус:** патч подготовлен 17.11.2026; на хостинг ещё не установлен.

## Согласованное правило

Поле **«URL источника» необязательное для всех типов источников**: официальный, картографический, научный, медиа/лицензия, наблюдение и прочий. Источником может быть печатная книга, справочник, отчёт без сайта или личное наблюдение. Не придумывать URL и не подставлять прочерк. При наличии ссылки допускается лишь корректный HTTP(S)-URL.

Для печатных материалов в `title` указать точное название, в `publisher` — автора/издателя (по возможности), в `comment` — год, издание, страницы и сведения о подтверждаемом факте. Для наблюдения в комментарии указать автора, место, примерный период и степень достоверности; не раскрывать точные места, если это нежелательно. Источник **всё равно обязателен при создании записи о встречаемости**, а запись должна иметь уровень подтверждения `verified_observation`, когда используется личное наблюдение.

## Что изменено

1. Убрано `required` и звёздочка с URL из двух форм источников (участки и виды рыб).
2. Клиентская валидация URL выполняется только для непустых строк; дата проверки и название остаются обязательными.
3. PHP `api/admin/directory/sources/save.php`: `sourcesUrl(..., false)`; непустой URL проверяется прежним валидатором.
4. При `url=''` не выполнять автоматический поиск дубля по одному пустому URL. Иначе две разные офлайн-книги ошибочно будут считаться одним источником.
5. Обновлены тесты и документация.

## Развёртывание

- SOURCE: сохранить копию локальных изменяемых файлов, распаковать ZIP в `E:\Project\native-places`, выполнить `npm --prefix admin run build`.
- HOST: сделать копию `/www/native-places.ru/api/admin/directory/sources/save.php` и действующего `/www/native-places.ru/admin/` сборки; заменить **только** файл `api/admin/directory/sources/save.php` из HOST-патча; затем загрузить новое содержимое `admin/dist` в действующую папку админки.
- Никакой SQL-миграции, API видов рыб и действующие сведения Дона не менять. Ничего не помещать в физическую папку `/admin/directory/` — она конфликтует с React SPA.
- Проверить под учётной записью администратора: создать два разных офлайн-источника без URL, выбрать их в подходящих формах. Проверить, что ошибочный непустой URL сервер отклоняет, и что существующие OSM URL работают. Без авторизации endpoint по-прежнему должен отвечать 401 JSON.

**Откат:** восстановить резервные копии `sources/save.php` и старой сборки админки; БД не изменять. Новые источники останутся в таблице, поскольку патч не выполняет DDL и не удаляет записи.
