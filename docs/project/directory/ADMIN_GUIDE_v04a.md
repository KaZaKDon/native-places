# Администратору: участки рек Native Places v0.4a

**Статус:** инструкция к подготовленному патчу, до установки неприменима.

1. Войдите администратором и откройте `/admin/directory` → «Реки и водоёмы» → «Участки рек».
2. Выберите из списка реку (например, опубликованный **Дон**, `river_entry_id=1` в проверенной ранее базе). Нельзя создать участок для озера, леса или несуществующего объекта.
3. Нажмите «Добавить участок». Укажите уникальный внутри реки slug (`vyoshenskaya`, это пример адреса, а не подтверждённая разметка), название не короче трёх символов. Ориентир, тексты и геометрию пока можно не вводить.
4. Для геометрии подготовьте **только нужный именованный участок** реки, проверенный по OSM/другому источнику. Не загружайте весь Дон в каждую запись. Выберите `.geojson`, проверьте линию на карте. Формат: `LineString`/`MultiLineString`, WGS84, не более 250 КБ/20 000 координат.
5. Для доказательства геометрии нажмите «Добавить источник». Укажите ссылку **на конкретную карту/объект**, дату проверки и лицензию (при необходимости). Источник выберется для открытого черновика. Источник OSM подтверждает географию, **не** виды рыб и не правовой режим.
6. Нажмите «Сохранить черновик участка». Обновите админку F5, снова откройте «Участки рек», выберите реку и «Редактировать» — проверьте тексты, источник и синюю линию.
7. Не ищите кнопку «Опубликовать»: в v0.4a её нет. Публичные страницы и SEO участков будут разработаны отдельно.

Редактировать опубликованные в будущем записи будет нельзя без снятия с публикации. Удаление и автоматическая нарезка реки пока отсутствуют. Существующие платные объявления не зависят от этих форм.
