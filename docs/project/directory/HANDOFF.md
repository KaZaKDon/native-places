## Принятые продуктовые решения

- **Не 7-я категория**: шесть действующих категорий платных объявлений сохраняются. Новый отдельный бесплатный «Справочник».
- Главная: три кнопки по центру — золотая «Исследовать карту», тёмная «Категории», золотая «Справочник» (золотые строго одинакового размера и цвета).
- В админке новая самостоятельная вкладка «Справочник мест» с подгруппами: воды, природные территории, охотничьи угодья, интересные места. Старый `/admin/dictionaries` не переименовывать и не смешивать.
- На карте: точки/линии/полигоны справочника отдельно от маркеров платных объявлений, посетитель может скрывать слои.
- Геоданные только из проверяемых картографических источников; реальные объекты и тексты — в базе/админке, никакого хардкода реки Дон в React.
- **Каждый ZIP-патч обязательно сопровождается обновлением проектной документации.** Работа строго по одному проверяемому шагу.

## Следующий шаг

1. В `E:\Project\native-places` распаковать **SOURCE ZIP** и выполнить `npm run build` (первой проверкой); затем `npm --prefix admin run build`.
2. После подтверждения сборок сделать резервные копии сайта/админки и загрузить **HOST ZIP** с сохранением структуры, предварительно сравнив действующие SEO-файлы и не перезаписывая чужих новых изменений.
3. Проверить публичные API без опубликованных объектов и защищённый endpoint публикации (без сессии должен 401). Разместить админку `admin/dist`.
4. Дополнить текст черновика «Дон» и опубликовать. Затем разместить публичную сборку корня `dist` — кнопка «Справочник» станет видна только вместе с рабочими маршрутами.
5. Проверить F5 `/directory` и `/directory/river/don`, 200 canonical, карту, sitemap. После этого можно продолжить масштабирование справочника.
