## Технические правила и известные ловушки

- `E:\Project\native-places` = React + docs + текстовые копии `docs/backend`. **Рабочий API/БД на хостинге**. Сверять production PHP перед патчами.
- Не создавать физическую `/www/native-places.ru/admin/directory/` (403 конфликтует с SPA). Настоящий API: `/www/native-places.ru/api/admin/directory/`. Резервная переименованная папка `admin/directory_backup_20261116` могла остаться на хосте — не удалять вслепую.
- Шесть категорий/оплаты объявлений не трогать; «Справочник» — **бесплатный отдельный раздел**, не седьмая категория.
- Два золотых CTA на главной одинакового размера; карта: синий Дон, далее план отдельного фиолетового контура ООПТ.
- Геометрия Дона пока только Вёшенский фрагмент; четыре линии OSM ≠ четыре именованных участка. Источник OSM — геометрия, а не ихтиофауна.
- Наблюдение окуня — личный опыт, точные даты не известны. Никаких выдуманных URL; URL необязателен **для всех источников**.
- Черновики и ИИ-картинки не должны оказываться публичными. В БД медиа `MEDIUMBLOB`, не путь к файлу внутри docroot.
