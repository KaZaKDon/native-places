# Справочник / получение настоящего русла реки Дон

Актуально для патча **v0.2**. Здесь нет нарисованных или автоматически сгенерированных координат Дона. Геометрию необходимо получить из открытых картографических данных, **проверить и сохранить** в черновике через админку.

## Сбор участка реки

1. Откройте [Overpass Turbo](https://overpass-turbo.eu/), наведите карту на **небольшой конкретный участок Дона** в Ростовской области. Увеличьте карту, чтобы её видимая область не включала весь Дон.
2. Вставьте запрос из `Don_OSM_overpass_turbo.txt`, запустите. Фильтр `name=Дон` и `waterway=river` ищет **кандидатные** линии в текущем окне карты, не удостоверяет их принадлежность основному руслу.
3. Сверьте выделенные линии визуально с картой и исходными OSM-объектами. Удалите посторонние линии до экспорта, если они обнаружены. Используйте **Export → GeoJSON**.
4. Откройте `/admin/directory` → «Реки и водоёмы» → «Дон» → «Редактировать» → «Выбрать файл .geojson / .json».
5. Убедитесь, что на превью показан правильный участок. Если «Файл превышает 250 КБ», сузьте область в Overpass Turbo и экспортируйте заново. **Не уменьшайте точность координат вслепую.**
6. В поле «Источник сведений» внесите точную ссылку на OSM-объект или страницу OSM/Overpass; сохраните черновик и перезагрузите админку. На публичной карте **ещё ничего не появится**.

## Данные, ограничения и лицензия

- Допускаются `Geometry`, `Feature`, `FeatureCollection` в GeoJSON. Несколько линий преобразуются в одну `MultiLineString`. При смешанных точках/полигонах форма выведет ошибку.
- Не более 250 КБ и 20 000 точек; координаты только `[долгота, широта]` в системе WGS84.
- Для реки — `LineString`/`MultiLineString`, для водоёма/угодий/лесов — `Polygon`/`MultiPolygon`, для родника/достопримечательности — `Point`.
- Исходные данные OSM доступны под **ODbL**. При использовании OSM геометрии обязательно указывать авторство `© OpenStreetMap contributors`, сохранять ссылку на источник и соблюдать условия ODbL. В превью уже есть видимая атрибуция OSM-картографической подложки.
- Обновления справочных данных (в том числе версия источника, проверка лицензии и границ) — задача модерации до публикации.
- Водные участки и границы угодий **не означают** право ловли рыбы или охоты; такая информация требует отдельной юридически корректной проверки.
