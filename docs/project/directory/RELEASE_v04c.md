# Native Places v0.4c — публикация видов рыб (код подготовлен)

**Дата:** 17.11.2026. **Статус:** патчи подготовлены, не установлены на production. Проверки на живой БД и в браузере не проводились. Номер версии v0.4c закреплён за публичными видами рыб; ООПТ и публикация именованных участков остаются в очереди.

## Состав

- `directory_species` — публикация/снятие вида через новый `api/admin/directory/species/publication.php` с админ-сессией, CSRF, транзакцией, проверкой двух текстовых блоков, не менее одного обоснованного факта присутствия вида на **опубликованном** водоёме и наличия изображения с авторством/основанием использования.
- Вместе с публикацией статусы привязок `directory_species_occurrences` и изображений `directory_media` становятся `published`. Снятие с публикации атомарно переводит их обратно в `draft` и скрывает публичные страницы/изображения.
- Журнал действий `directory_species_events` — новая миграция `20261117_directory_species_publication_v04c.sql`. Она **создаёт одну таблицу**, не меняет `places` и ранее созданные справочные таблицы.
- Публичные API `api/directory/species/index.php`, `api/directory/species/show.php`, `api/directory/image.php`, дополнение `api/directory/show.php` для блока рыб у реки/озера. Все запросы допускают только опубликованный вид, опубликованную привязку и опубликованную родительскую реку/озеро.
- Именованный участок Дона остаётся **черновиком**, поэтому его название, slug и геометрия в публичном API вида не выдаются. Сведения о присутствии окуня показываются на уровне опубликованного Дона как **личное наблюдение** с указанием источника (без искусственного превосходства научных/официальных источников над личными). Приватные заметки и комментарии источников публично не раскрываются.
- Новая клиентская страница `/directory/species/:slug` с описанием, фото/ИИ-иллюстрацией, источниками и ссылкой на водоём; блок видов на `/directory/river/don`. Изображение имеет публичную атрибуцию происхождения в карточке вида.
- Серверный HTML/SEO: новый `seo/species.php`, маршрутизация в `seo-router.php`, список рыб на серверной странице Дона, индивидуальные Title, Description, Canonical, Schema.org (`DefinedTerm`, BreadcrumbList), Sitemap только опубликованных видов.
- В админке видны статусы «Черновик/Опубликован», кнопки публикации/снятия и ссылка на публичную карточку. Редактирование/удаление опубликованных записей остаётся заблокированным до снятия с публикации.

## Ограничения и безопасность

1. **Окунь и его изображение пока не опубликованы**. Наличие кода не означает публикацию.
2. Статус научного источника, книги или личного наблюдения **не гарантирует** актуального наличия рыбы. Дата `verified_at` — дата сверки записи, не дата самой рыбалки.
3. URL источников не обязателен. Для книги нужны идентифицирующие реквизиты; для личного наблюдения — характер, место и примерный период в закрытом описании источника.
4. Не разглашаем личные/чувствительные детали из `notes` и `source.comment` — публично только название источника, тип, дата сверки и (если опубликован) названный участок.
5. Правовая основа фото обязательна, в том числе специальное обозначение ИИ-иллюстрации; изображение, найденное в интернете, не считать ИИ-генерацией.
6. Если основная река позднее снята с публикации, API вида и его изображения перестанут быть публично доступны при отсутствии других опубликованных связей. SEO-кэши поисковых систем обновляются не мгновенно.
7. Фотографии остаются в `MEDIUMBLOB` MySQL. Вынос в закрытое хранилище — отдельная будущая задача.
8. Публикация **именованных участков**, их собственные SEO-страницы и геометрия на общей карте в этом выпуске **не реализованы**; это следующий этап.
9. Не меняются шесть платных категорий, таблица `places`, тарифы, объявления, платежи, основной маршрут `/directory/river/don` и его геометрия.

## Приёмка на хостинге после пошаговой установки

- До публикации: `/api/directory/species/show.php?slug=okun-rechnoy` = 404 JSON; `/directory/species/okun-rechnoy` = HTTP 404/noindex; приватное изображение недоступно; Sitemap не содержит вид.
- После публикации через авторизованную админку: `200` JSON, карточка рыбы и ИИ-иллюстрация, блок рыбы у Дона, корректный canonical, присутствие в Sitemap.
- После снятия с публикации: вновь 404 JSON/HTML и 404 изображения; старый Дон остаётся доступен.
- Проверка статуса чернового именованного участка: его URL/название не раскрываются публично.
