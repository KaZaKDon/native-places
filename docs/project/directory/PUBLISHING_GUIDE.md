# Пользовательская инструкция — справочник v0.3

## Создание и публикация

1. Войти в админку как **Администратор** → «Справочник мест» → «Реки и водоёмы».
2. У объекта «Дон» нажать **Редактировать**. Уточнить название и регион, заполнить оригинальный подробный текст и проверяемые сведения; добавить ссылку на источник. GeoJSON 117 точек / 4 участка уже сохранён в черновике (проверено 15.11.2026).
3. «Сохранить черновик», вернуться к списку. Кнопка **Опубликовать** доступна только для черновика.
4. «Опубликовать» → подтвердить. При коротком/дублирующем содержимом API откажет и сообщит, что исправить.
5. После публикации проверить `/directory` и `/directory/river/don`. Новый объект появится на общей карте, если у него есть геометрия.
6. **Снять с публикации** — вернуть объект в черновик. После этого можно редактировать и снова публиковать. При снятии с публикации публичный API перестаёт выдавать запись; для браузерного HTML возможна задержка кеша.

## Что видит посетитель

- На главной 3 кнопки: карта / категории объявлений / справочник.
- `/directory` — список бесплатных информационных объектов (без цен и оплаты).
- Страница реки — название, регион, текст, ссылка на источник и русло на карте.
- `/map` — две галочки: «Объявления» и «Справочник». По реке/территории — подсказка со ссылкой на страницу объекта.

## Права и ограничения

- Чтение справочника: без регистрации, бесплатно.
- Создание/редактирование/публикация: пока только admin.
- Нельзя публиковать пустые или неподтверждённые данные. Ограничение длины текста — это технический фильтр, но содержание администратор проверяет сам.
- Справочник видов рыб, истории посетителей, фотографии и ассоциация с платными объявлениями — **следующие этапы, в v0.3 отсутствуют**.
- При нехватке геометрии объект может иметь карточку без карты. Для охотугодий публиковать контур только на основе достоверного источника.
