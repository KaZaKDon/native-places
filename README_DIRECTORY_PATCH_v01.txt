Native Places / СПРАВОЧНИК МЕСТ / v0.1
=======================================
Патч только с изменёнными и новыми файлами. Применять поверх ТЕКУЩЕГО локального проекта, не поверх старой копии.

1. Сначала сделайте резервную копию локального проекта.
2. Распакуйте содержимое архива SOURCE в КОРЕНЬ проекта (где package.json и admin/).
3. Выполните: npm --prefix admin ci
4. Выполните: npm --prefix admin run lint && npm --prefix admin run build
5. Не загружайте frontend на хост до подготовки БД и PHP.
6. В отдельном архиве HOST: новый каталог api/admin/directory/ и миграция db/migrations/....sql.
   Резервная копия БД обязательна. SQL не запускается автоматически. НИЧЕГО в существующем API не заменяется.
7. После SQL перенесите ТОЛЬКО файлы api/admin/directory/*.php в соответствующий путь НА ХОСТЕ.
8. Затем соберите и загрузите актуальную админку согласно действующей схеме развёртывания.
9. Откройте /admin/directory под admin, создайте тестовый ЧЕРНОВИК и проверьте повторное редактирование.

ОГРАНИЧЕНИЯ: код подготовлен по текстовым API-документам старого архива; хостовая авторизация/БД не были доступны для запуска интеграционных тестов. Сверить действующий require-admin.php, cors.php, config/database.php перед установкой. Публичная страница, третья кнопка, sitemap и слой карты в v0.1 НЕ добавляются.
Подробности: docs/project/directory/HANDOFF.md, ADMIN_GUIDE_DRAFT.md.
