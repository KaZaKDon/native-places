Native Places — SOURCE PATCH v0.3 — 15.11.2026
=============================================
Требуется установленная локальная версия v0.2 и уже исправленный F5 v0.1.1.

1. Сделать копию E:\Project\native-places.
2. Распаковать ZIP в корень локального проекта с сохранением путей,
   сверив изменения с собственными локальными правками.
3. Первая проверка (PowerShell в E:\Project\native-places):
   npm run build
   При успешном результате по отдельной проверке:
   npm --prefix admin run build
4. В архиве КОД публичного сайта и админки — только исходники. Готовые
   dist-файлы появятся после сборки на компьютере пользователя.
5. Не выкладывать на хост публичный dist до установки HOST PATCH
   и успешной публикации хотя бы одного содержательного объекта.
6. Отдельный HOST PATCH содержит PHP API и SEO, SQL НЕ требуется.
7. Текстовые копии PHP находятся в docs/backend и docs/seo.
8. Подробная раскладка, проверки, права и откат: docs/project/directory/
   RELEASE_v03.md, PUBLISHING_GUIDE.md, HANDOFF.md.

Важно: действующие шесть платных категорий и платежи не изменяются.
Справочник отдельный и бесплатный. Кнопки "Исследовать карту" и
"Справочник" одинаковые золотые и одного размера.
