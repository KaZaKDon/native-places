Native Places — DIRECTORY GEOJSON PREVIEW v0.2 (15.11.2026)

Состав: локальные исходники админки + обновленная проектная документация.
СЕРВЕРНЫХ PHP/SQL ИЗМЕНЕНИЙ В ЭТОМ ПАТЧЕ НЕТ.

1. Распакуйте ZIP поверх E:\Project\native-places с сохранением структуры.
2. В PowerShell из корня проекта:
   node --test admin/src/pages/Directory/*.test.js
3. Затем выполните:
   npm --prefix admin run build
4. При успешной сборке и после копии старого admin/dist на хостинге
   загрузите содержимое E:\Project\native-places\admin\dist
   в используемую публичную папку админки (ту же, куда загружали v0.1).
5. Откройте /admin/directory → Река «Дон» → Редактировать.
   Выберите проверенный .geojson, проверьте линию на карте,
   укажите источник, нажмите «Сохранить черновик», нажмите F5.

Ограничения: v0.2 — только геометрия в ЧЕРНОВИКЕ; без публичных
страниц, слоев сайта, платежей, миграций и кнопки «Справочник».
Настоящие OSM-координаты Дона в ZIP НЕ включены. Источник и порядок
экспорта описаны в docs/project/directory/geodata/README.md.

При ошибке сборки остановиться, на хост ничего не загружать.
