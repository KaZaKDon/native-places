Native Places — SOURCE v0.4b.2 (2026-11-17)

Содержит только изменённые файлы React-админки, тесты, текстовую копию PHP и документы.
Патч НЕ установлен и не меняет публичный сайт.

Установка:
1. Сохранить резервную копию локального E:\Project\native-places.
2. Распаковать ZIP поверх E:\Project\native-places с сохранением структуры.
3. В PowerShell из корня проекта: npm --prefix admin run build
4. Перед развёртыванием дождаться успешной сборки, не обновлять PHP вслепую.

Затем:
- Сохранить бэкап текущего /www/native-places.ru/api/admin/directory/media/upload.php.
- Сверить рабочий серверный файл с патчем; заменить только этот PHP из HOST ZIP.
- Загрузить содержимое admin/dist в /www/native-places.ru/admin/.
- НЕ создавать /www/native-places.ru/admin/directory/; старый конфликт давал HTTP 403.
- Проверить форму «Виды рыб → Окунь речной → Загрузить изображение».
- Для ИИ-иллюстрации ввести инструмент генерации и подтвердить право на конкретный файл.

Новая SQL-миграция НЕ требуется.
Фото/иллюстрации остаются ПРИВАТНЫМИ черновиками.
